🤖 Jarvis - Python Desktop Voice Assistant
A powerful, custom-built desktop voice assistant developed in Python. Jarvis gives you full control over your computer through voice commands, handles web searches, plays media, manages system tasks, and includes a fallback text input mode for seamless operation.

✨ Features
🎙️ Voice Recognition & Fallback Control: Listens to user commands via microphone using sounddevice and speech_recognition, with a built-in manual typing fallback option.

🌐 Web & YouTube Automation: Open popular websites like Google and YouTube, or instantly play songs and videos on YouTube using voice commands.

📚 Wikipedia Integration: Instantly fetch summaries of any topic directly from Wikipedia.

💻 System & Desktop Control: Open applications like Notepad and Command Prompt, take screenshots, adjust system volume, and manage power states (shutdown).

🗣️ Text-to-Speech Output: Communicates back with natural text-to-speech responses using pyttsx3.

🚀 Installation & Setup
Clone the repository:

Bash
git clone https://github.com/your-username/jarvis-assistant.git
cd jarvis-assistant
Install required dependencies:

Bash
pip install numpy sounddevice speechrecognition pyttsx3 pywhatkit pyautogui wikipedia
Run the assistant:

Bash
python jarvis.py
